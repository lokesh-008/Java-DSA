# 🌳 Binary Trees

This folder contains binary tree-based interview problems that focus on **tree traversal, recursion, depth-first search (DFS), and binary tree properties**. These problems help build a strong foundation for solving tree-related questions frequently asked in coding interviews.

* Binary Tree

---

## 🎯 Learning Outcomes

After completing this folder, you will be comfortable with:

* Understanding the structure of a binary tree
* Performing preorder, inorder, and postorder traversals
* Applying recursion to tree problems
* Using DFS for binary tree problems
* Understanding tree height and depth
* Recognizing common binary tree patterns in interview questions

---

⭐ **Binary Trees are a fundamental DSA topic and form the foundation for more advanced concepts such as Binary Search Trees, tree recursion, DFS/BFS, and many interview-level tree problems.**
