# 📚 Stacks

This folder contains stack-based interview problems that focus on the **Last In, First Out (LIFO)** principle. These problems help build a strong understanding of stack operations, expression evaluation, balanced parentheses, and other common stack patterns frequently asked in coding interviews.

---

## 📚 Problems

| # | Problem | Difficulty | Technique |
|---|---------|------------|-----------|
| 1 | Valid Parentheses | Easy | Stack |
| 2 | Min Stack | Medium | Auxillary Stack |
| 3 | Largest Rectangle in Histogram | Hard | Monotonic Stack |
| 4 | Basic Calculator II | Medium | Stack |
| 5 | Evaluate Reverse Polish Notation | Medium | Stack |

---

## 🧠 Concepts Covered

- Stack (LIFO)
- Push & Pop Operations
- Parentheses Matching
- Character Processing
- Expression Validation

---

## 🎯 Learning Outcomes

After completing this folder, you will be comfortable with:

- Understanding the LIFO principle
- Solving balanced parentheses problems
- Using stacks for expression validation
- Implementing stack-based algorithms
- Recognizing stack patterns in interview questions

---

⭐ **Stacks are one of the most important linear data structures in DSA and are widely used in parsing, expression evaluation, monotonic stack problems, and depth-first traversal.**
